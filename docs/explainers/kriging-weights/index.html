How Kriging Gets Its Weights

The weights are not read straight off the semivariogram. The curve feeds a small set of equations, and the weights are their solution. Here is every step for four measured temperatures and one unknown point, worked with real numbers.

You do not need any of this for Lab 8 or the exam: ArcGIS Pro's Kriging tool does all of it for every cell. It is here for anyone who wants to know what the tool is doing.

Two kinds of distance, not one

Say you want Z0, the value at an unmeasured point, from four measurements Z1…Z4, and the semivariogram model is already fitted. The first step is the one you would guess: measure the distances D1…D4 from the unknown point to each measurement, and read the semivariances V1…V4 off the curve at those distances. They say how far off each measurement is likely to be from the value you want.

Kriging also reads the curve at the distance between every pair of measurements: D12, D13, D14, D23, D24, D34, giving six more semivariances Vij. Those say how much the measurements repeat each other. IDW never looks at them, and they are what make kriging different.

Read all ten semivariances off the curve

The model here is spherical, with a nugget of 2, a sill of 20 (°F²) and a range of 50 km. Every number you need comes from this one curve.

The equations

There are five unknowns: the four weights λ1…λ4, plus one helper number m. You get one equation per measurement and one that forces the weights to add up to 1:

λ1·0    + λ2·V12 + λ3·V13 + λ4·V14 + m = V1
λ1·V12 + λ2·0    + λ3·V23 + λ4·V24 + m = V2
λ1·V13 + λ2·V23 + λ3·0    + λ4·V34 + m = V3
λ1·V14 + λ2·V24 + λ3·V34 + λ4·0    + m = V4
λ1      + λ2      + λ3      + λ4           = 1the weights add to 1, so the estimate is not biased high or low

Then the estimate itself is just the weighted average, exactly as in IDW:

Z0 = λ1Z1 + λ2Z2 + λ3Z3 + λ4Z4

Each row reads in plain words like this: "blend the measurements so that, judged by the curve, the blend is as far from Zi as the unknown point is." The helper m (a Lagrange multiplier) is what lets the "add up to 1" rule fit into the same system. It never multiplies a temperature, but it comes back at the end as part of the error estimate.

What the gray block did

  • Z₃ and Z₄ are the same distance from Z₀ but get different weights (0.095 against 0.122). Z₃ sits closer to Z₂ (36.6 km against 41.7), so part of what it would tell you, Z₂ already told you. IDW gives them identical weights because it only sees D3 = D4.
  • Clustered samples share their weight. Z₃ and Z₄ are only 8 km apart, so the system treats them as partly one measurement. Add a fifth station right on top of Z₃ and the pair's weight would mostly split, not double.
  • Weight follows the curve, not 1/d². Between 25 and 30 km the curve is already near its sill, so Z₂ and the western pair count almost equally. IDW's 1/d² piles 73% onto the nearest point.
  • A weight can go negative. When one sample sits directly behind another as seen from Z₀, the far one can get a small negative weight. The near one "screens" it.

A bonus you get for free: the error

The same solution gives the expected squared error of this estimate:

σ² = λ₁V₁ + λ₂V₂ + λ₃V₃ + λ₄V₄ + m = 11.21 °F²  →  σ ≈ 3.3 °F

So Z₀ ≈ 61.5 ± 3.3 °F. Do this for every cell and you get ArcGIS Pro's Output variance of prediction raster: small near samples, large in the gaps. IDW has no equivalent.

Connections to the lecture and Lab 8

  • The flat kriging panel in the lecture's six-methods test. When the range is near zero, every V and Vij equals the sill. Every row of the system then looks the same, the weights come out equal (¼ each here), and Z₀ is the plain average. That happens in every cell, which gives the flat surface.
  • A big nugget. The nugget lifts every off-diagonal Vij while the diagonal stays 0, so the samples look less alike to each other and the weights spread out toward equal. The surface smooths toward the average.
  • In ArcGIS Pro the Kriging tool builds and solves this system once for every output cell, using that cell's nearest samples (by default, a variable search radius with 12 points). With 12 neighbors the system is 13 × 13.
  • Ordinary kriging is the version on this page: the mean is unknown, so the weights must add to 1. Simple kriging assumes the mean is known and drops the last row and m.
Where the equations come from

Write the estimate as Σλᵢ Zᵢ with Σλᵢ = 1. Using the semivariogram, the expected squared error of that estimate is

E[(Ẑ₀ − Z₀)²] = 2 Σᵢ λᵢ Vᵢ − Σᵢ Σⱼ λᵢ λⱼ Vᵢⱼ

Minimize it subject to Σλᵢ = 1, with a Lagrange multiplier. Setting the derivative with respect to each λᵢ to zero gives Σⱼ λⱼ Vᵢⱼ + m = Vᵢ, which are rows 1–4, and the constraint is row 5. Substituting the solution back in gives σ² = Σ λᵢVᵢ + m. Kriging is "best" in exactly this sense: of all weightings that add to 1, it has the smallest expected squared error, if the semivariogram is right.
